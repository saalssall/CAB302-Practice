# Java Exercises 
## This is a simple *Java program* that demonstrates some basic object-oriented concepts such as **classes**, **objects**, and **methods**.

## Features

- Getting started with java
- Learning java syntax
- Practicing java data structures
- Working with objects, classes, and methods
- Error and file handling
- I/O streams
## Requirements

- Java 17+
- Git (optional, for version control)
